FOLDER ASET GAMBAR - OUTBOUND KEDIRI
=====================================
File SVG di folder ini (logo.svg, placeholder-forest.svg) adalah placeholder
karena foto asli kegiatan tidak tersedia untuk disertakan langsung di kode.

Cara mengganti dengan foto asli:
1. Upload foto asli Anda ke folder ini, contoh:
   - hero-beranda.jpg
   - venue-pagung-adventure.jpg
   - dokumentasi-rafting-01.jpg
   - tim-fasilitator-danang.jpg
2. Di setiap file HTML, cari elemen dengan class "ph-img" (placeholder image)
   lalu ganti atribut src="assets/img/placeholder-forest.svg" menjadi path
   foto asli Anda, contoh:
   src="assets/img/hero-beranda.jpg"
3. Sesuaikan juga og:image di setiap <head> halaman agar preview share
   media sosial menampilkan foto asli.

Rekomendasi ukuran:
- Hero / gambar besar: 1600x1200px, format .jpg/.webp, dikompresi < 300KB
- Kartu paket/venue/galeri: 800x800px atau 800x600px
- Logo: 200x200px, format .svg atau .png transparan
